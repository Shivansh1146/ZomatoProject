Quick Tips

  • Item name must be unique within the same restaurant.
  • Label examples: Bestseller, Must Try, New.
  • Select VEG or NON-VEG carefully — this affects how the item is shown to customers.
  • Variants let you add sizes (Small, Medium, Large) with different prices.
  • Enable "Manage Inventory" on a variant to track stock count.
